# interactive-mv-skill

一个可复用的 Skill：**根据一首歌做出可交互的网页版 MV**。

## 能做什么

给一首歌（音频 + 歌词时间轴），生成一个高交互的网页 MV：

- 全屏 Canvas 舞台，代码绘制的角色（不用任何图片素材）
- 大字卡拉 OK 歌词，逐字跟唱；可点击的歌词列表，点哪句跳哪句
- 点画面惊起粒子、按住拖拽生风（粒子/围巾/风力条联动）
- 点角色弹出台词、收集金叶子、换天气、落叶雨、送心动、发弹幕
- 结尾双分支结局（如"原谅他" vs "随风错过"），可重选

## 实测案例

王力宏《爱错》交互 MV：3 分 59 秒原音频驱动，14 镜头、38 句精确时间轴，
全部交互经探针实测验证（播放/暂停、歌词跳转、结局分支均通过）。

## 做法要点（已沉淀为 Skill）

1. 音频先压到 128kbps（10MB → 4MB），手机网才带得动；时长必须分毫不差
2. 播放失败不能静默吞掉：显示"加载中"，到位自动开播，卡住自动重拉
3. 全站由 `audio.currentTime` 驱动的单循环调度，跳转天然同步
4. 交付前探针验证：点播放时间走、点歌词能跳、结局能进

## 文件说明

- `SKILL.md` —— Skill 正文：AI 按此流程执行即可复刻
- `skill.yaml` —— Skill 元信息（名称、描述、分类）

## 安装

把本仓库内容放到 Muse 的 custom skills 目录即可：

```bash
cp -r . ~/workspace/custom-skills/interactive-mv/
```

之后对 AI 说"做个交互 MV"就会按这套方法开工。
